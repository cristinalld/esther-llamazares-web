# Aprobación de noticias

Cada mañana GitHub busca noticias recientes sobre Esther Llamazares.

## Aprobar

1. Abre la pestaña Issues del repositorio.
2. Entra en una propuesta cuyo título empiece por [Prensa].
3. Revisa medio, fecha, titular y enlace.
4. Añade la etiqueta prensa-aprobada.

La noticia se incorporará a la web y la propuesta se cerrará automáticamente.

## Rechazar

Cierra la propuesta sin añadir la etiqueta de aprobación.

Ninguna noticia se publica únicamente por haber sido encontrada.
